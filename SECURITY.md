# Cronhelm Security Policy

## How can I report a security bug?

Please report security issues privately by email to hello@littlebig.co with the subject "Cronhelm security". Include the plugin version, what you found and, if you can, steps to reproduce it. You will get an answer within a few working days and credit for a valid report if you want it.

Do not report security issues in public issues or forums. Thank you.
